🏥 HealthCare Plus – Hospital Website (React + Vite)

A modern, responsive hospital website built using React (Vite + TypeScript).
This project demonstrates reusable component architecture, clean UI structuring, and scalable frontend design.
It is designed as a production-style frontend suitable for portfolio and placement interviews.

🚀 Tech Stack
* React (Vite)
* TypeScript
* Component-Based Architecture
* CSS
* ESLint
* Reusable UI Components
